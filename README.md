# 开拓生存 · 材料计算器

一个为《开拓生存》制作的网页工具：**材料合成计算**、**戒指合成路线**、**挂机时长估算**、**属性面板计算**、**刷怪收益排行**、**开拓农村（建厂 / 员工 / 羁绊效率与资金统计）** 与 **开拓工厂（各级材料合成路线）**，部署在 Cloudflare Pages 上。

全部游戏数据（物品、配方、怪物掉落、召唤成本、装备词条、Buff 定义）不硬编码，实时来自游戏服务器 `kt.ikui.vip` 的数据接口，经边缘代理缓存加速——游戏更新配方后，页面无需发版即可拿到最新数据。

唯一的例外是**开拓农村 / 开拓工厂**：这部分数值不在数据接口里，而是打包在游戏客户端 bundle 中，因此由 `scripts/sync-farm-defs.mjs` 提取后内嵌在页面里（游戏更新数值后重跑一次即可，详见下文）。

## 功能

### 📦 材料合成计算

- 同时添加多个合成目标（锻造、NPC 兑换、虚空商队、区域配方统一纳入下拉选择）
- 递归展开合成树，可逐层折叠查看每一级的用量
- 自动汇总到**原子材料**（不可再合成的材料），按数量排序
- 标记每种材料是否**可刷怪获得**，并给出期望掉落最高的怪物
- 装备图标/名称悬浮可查看**属性提示**（品质、槽位、词条、特效）

### 💍 戒指合成路线（魔盒机制）

- 22 枚可合成指环按品质分区（极品 / 稀有 / 精粹 / 奇巧）逐枚查看**获取路线与成功率**
- 机制与游戏客户端源码（`HoradricPanel`）对齐：
  - **魔盒 · 锻造（转化）**：同一品质页签内凑齐 **3 份配方材料**（三个不同，或两份相同 + 一份不同；不能三份全相同）→ **50%** 出其中一个；失败或材料不匹配即**炸炉**（材料全部消失）
  - **魔盒 · 合成（三合一）**：**3 枚不同的同品质戒指**（各 1；工坊可直接锻造的镜像铁傀 / 古墓吞噬 / 侵染星辰 / 夜翼魔徽 不能当祭品）+ 对应**绑定材料** → **必出**该材料对应的戒指，**100%** 不炸炉
  - **极品指环不在魔盒内**：由工坊锻造（极品铸模×3 + 材料）
- **期望材料按成功率与三份装填折算**：定向出货按「2 份本配方 + 1 份同品质配平配方」计（每轮出目标约 1/3 → 期望 6 份本配方 + 3 份配平配方/件）；100% 产线按 1 份计，40% 工坊配方按 2.5 次/件计
- 支持输入目标数量，全部期望材料按数量缩放；铸模升级链可在「材料合成计算」页签递归展开

### ⏳ 挂机时间计算（含击杀耗时估算）

- 输入目标材料数量，选择刷取怪物，估算需要击杀的次数与**挂机总时长**
- 掉落按**期望值**计算：`掉率 × 掉落数区间均值`，宝袋自动按 loot table 展开
- **击杀耗时估算**：可选择「当前配装」或任意已保存配装 + **击杀算法（在线每刀一杀 / 离线每秒最多5只）**，按属性面板的期望伤害自动估算每只击杀秒数（物理伤害按怪物物理抗性折算 `×100/(100+有效抗性×1.5)`，护甲穿透按百分比削减怪物抗性；魔法/真实伤害不受物理抗性影响；怪物每秒回血从输出中扣除，DPS 不足会提示无法击杀；副手弓按固定连射射速计入）；行内「秒/只」可覆盖
- 怪物战斗数值（生命/抗性/回血）口径与游戏 Wiki 一致：品阶基础值 + monsterMod 修正（hpSet/hp/res），Boss（尸王/琉璃王等）用固定血量与回血
- 每只怪物击杀秒数可全局默认、可按行覆盖（召唤 / Boss 自行估计）
- 召唤成本（召唤币、召唤材料）按击杀数换算并汇总
- 支持从合成统计**一键带入**所有可刷材料

### 💰 刷怪收益排行

- **绑定装备预设**：选择「当前配装」或任意已保存配装，按该配装的期望伤害估算每种怪的击杀耗时，计算刷什么最赚钱，列出**时薪 Top 5**；**团队Boss（尸王/琉璃王）已排除**（一次性召唤战斗，非刷怪场景）
- **两种击杀算法可选**：
  - **在线**（默认）：每刀最多杀一只，按整刀结算——所需刀数 = ceil(怪物血量 ÷ 单个攻击间隔净伤害)，击杀耗时 = 刀数 × 攻击间隔（一秒三刀一秒最多杀 3 只）
  - **离线**：离线结算按有效 DPS 折算击杀数，**每秒最多杀 5 只**
- **收益口径**：`时薪 = (期望掉落折价 − 召唤成本) ÷ 击杀秒数 × 3600`
  - 期望掉落：`期望数量 × 商店出售价`（含神域币，宝袋自动展开），机会成本口径
  - 召唤成本：召唤神域币 + 召唤材料 × 商店出售价
  - 击杀耗时：物理伤害按怪物抗性折算（护甲穿透削减抗性），魔法/真实伤害不受物理抗性影响，副手弓按固定连射射速计入，怪物回血从输出中扣除；**DPS 打不过回血的怪自动排除**
- **自定义时长**：输入刷怪时长（小时），每张卡片同时显示时薪与该时长的预计总净赚、总击杀数
- **明细透明**：每张卡片分列「期望掉落/只」与「召唤成本/只」逐项金额（`单价×数量=小计`）；无商店卖价的材料不计入金额，单独列入「未估价材料」提示，供自行判断
- 排行概要显示算法与核算范围（可刷怪数 / Boss 排除数 / DPS 排除数）；抗性开关与挂机页独立

### 🏡 开拓农村（建厂 / 员工 / 羁绊 · 效率与资金统计）

- **建厂模拟（1～20 级）**：土地网格对齐游戏内「开拓农村」面板（4 列地块、钉子户 / 超级钉子户角标、`Lv.N · 岗位 x/y`）；每块地块可建 1 座建筑，支持选建筑 / 定等级（Lv.1～20）/ 选地块（普通 10 万 · 钉子户 100 万 · 超级钉子户 200 万地价）
- **口径与游戏客户端一致**（数值直接提取自游戏 bundle，已独立校验）：
  - 等级倍率 `1+(等级−1)×0.2`（Lv.20 = 4.8 倍）；员工编制 `min(等级, 6)`
  - 每小时产出 = `BASE_OUTPUT(10) × 效率 × 等级倍率`，按在岗员工**求和**（不是取平均）；副产物 = 产出 × 副产物概率
  - 时薪 = `基础薪资 × 加薪倍率 × 10000 × 羁绊折扣`；机器人 / 实习猪 / 机器猪无薪，黑客猪为**反向创收**（负薪资）
  - 烧炭厂：原料 → 木炭 **1:1**，且原料上限**逐个员工截断后求和**（客户端 `jc/Hc` 行为）
- **员工选择**：6 个岗位卡（3×2，解锁按等级）；可选员工、**加薪**（每次 +10%，上限 ×2，与游戏内「涨薪」按钮一致；效率与时薪同步缩放）、休假 / 上工、损坏 / 修好（机器猪损坏停工，效率 0）
- **组合羁绊**：实时判定 15 组羁绊（效率加成 / 薪资折扣 / 跑路率控制 / 机器翻倍等）并标注激活位于哪座建筑；「集群过载 / 自动运维」在客户端是硬编码效果，界面会明确标注「羁绊本身不再额外加成」
- **统计面板**：`💰 每小时净薪资`（应付薪资 / 待业薪资 / 反向创收 / 净支出 + 每日折算）、`📦 材料产出效率`（每种材料 /时 与 /日，消耗的原料按负数计）、`📊 员工效率统计`（基础效率 → 加薪 → 羁绊 → 最终效率 → 时薪 → 产出）、`🎯 建厂与升级一次性成本`（地价 + 建厂 + 从 Lv.1 升到当前等级的消耗，含金币 / 升级材料 / 灰烬）
- **猪才市场**：可加入待业员工，按每小时期望薪资的 10% 计费（负薪资按 0 计），并计入净支出

### 🏭 开拓工厂（各级材料合成路线）

- 覆盖客户端全部 **30 种工厂材料 / 18 条配方 / 8 个机器**（切削机、辊压机、热力辊压机、热力搅拌机、热力压块机 + 原料仓 / 储物仓 / 储物总仓）
- **阶级自动推导**：原料 = 0，产物 = `1 + 输入最高阶级`，得出「原料 / 一级产物 / 二级产物 / 三级产物 / 四级产物 / 五级产物」，与游戏内总仓库分列一致
- **合成路线查询（支持多个目标）**：可添加任意多个目标产物 + 数量（`＋ 添加目标产物` / `×` 移除），逐个递归展开到原料；**所需原料、机器批次数 / 秒数 / 小时数、燃料均按全部目标合计**（机器工时按每种 N 台并行折算，并标出瓶颈机器）
- **各级材料卡片**：逐条显示配方（输入 → 产出 × 数量 · 单次耗时）、单台产率（/时）、折算原料，热力机器额外标出燃料消耗
- **燃料**：燃料值 = 每个燃料可支撑的秒数（木炭 60s / 焚晶 30s / 炽热核心 600s），满载时按 `3600 ÷ 燃料值` 个/时消耗；有商店价的燃料给出金币折价
- 原料卡片会反向标注**农村产出建筑**（如安山岩 ← 安山岩采石场），并列出商店出售价（有价时）

### 👤 属性面板计算

- 按游戏装备栏布局（头盔/胸甲/护腿/靴子/主手 + 护符/项链/戒指/图腾/副手共 10 槽，护符仅 1 个可用槽位）自由搭配装备，实时计算**完整属性面板**
- 计算公式逐条对齐游戏客户端源码的 Calc 系列：`生命 = round((基础20+flat)×(1+pct/100))`、`物伤 = round((基础5~10+装备)×(1+pct/100))`、`攻频 = 1.2×(1+min(攻速,30)/30)+急速×0.35`（实战四舍五入取整）等
- **护符镌刻台**：装备普通/精工/大师护符后按品级选择 1~3 条词条（词条池与数值取自游戏 Wiki：普通 4 条 / 精工 7 条 / 大师 11 条，等概率可重复），支持**太古**开关（数值向上取整 ×1.25，名称加 ★），并按游戏规则预览命名（完美的/有瑕疵的/残余的）
- **收藏室（装备库）**：武器库 / 盔甲库 / 副手库 / 指环库四页签，卡片布局对齐游戏装备库 UI；勾选已入库装备即把收藏属性计入面板（盔甲套装每件一份加成、四件放满额外加一份；指环库按品质分区（极品/稀有/精粹/奇巧），同一品质的指环全部入库再得该品质的集齐加成，如极品集齐 +5% 伤害减免）
- **收藏数值为游戏真实数据**：内置默认值直接提取自游戏真实数据——`weaponVaultDefs / armorVaultDefs / offhandVaultDefs`（2026-09-07，经登录态 `/api/game/state` 接口获取，非公告转述）；`ringVaultDefs / ringVaultSetBonuses`（2026-09-12，V2.12 新增指环库，取自游戏客户端内置定义，与 V2.12 更新日志数值一致）。游戏更新后可点「⬇ 从游戏导入」粘贴最新 state JSON 一键刷新（localStorage 持久化，可随时恢复内置值；老版本 state 未带指环库时自动保留内置指环数据）
- **额外加成**支持手动填入其他来源加成（未收录的收藏室套装等）
- 装备 Buff 自动聚合（套装同名不叠加，取最高等级），并在面板中展示效果说明
- 每项属性附带**贡献明细**（装备 +X ｜ 护符 +Y ｜ 收藏 +Z ｜ 额外 +W），攻速超上限、唯一装备重复佩戴会给出提示
- **输出估算**：近战期望（单次期望 × 实战取整刀数）+ 副手弓（远程伤害 × 连射，固定射速不受攻速影响）+ 合计
- 配装方案可保存/载入（localStorage 持久化），方便横向对比多套搭配

## 技术要点

- **零构建、零依赖前端**：单个 `index.html`，原生 JS + CSS，无框架无打包
- **数据实时化**：页面每次访问经 `/api/data/defs` 拉取上游数据；失败自动回退 `localStorage` 离线缓存；页面驻留时每 30 分钟自动刷新，切回标签页超过 10 分钟也会刷新
- **两个 Cloudflare Pages Functions 边缘代理**：
  - `functions/api/data/defs.js` — 代理游戏数据 API，边缘缓存 5 分钟，上游 5xx/超时自动重试
  - `functions/source/[[path]].js` — 代理上游图片服务器（游戏图标为 HTTP 资源，需转成同源 HTTPS 才能在页面上显示），边缘缓存 1 小时；**多源回退**（lanxi 隧道 → 直连旧 IP），隧道域名失效后可通过 Pages 环境变量 `IMAGE_PROXY_ORIGIN` 免代码更新新地址
- **图标多级回退**：上游代理失败时自动切换到本地 `icons/` 镜像（按文件名匹配）；游戏新增物品后执行 `node scripts/sync-icons.mjs` 一键补齐镜像（`--check` 只报告不下载），避免代理挂掉时新物品贴图空白
- 免费额度友好：数据接口每个边缘节点最多 5 分钟回源一次，图片缓存 1 小时，Pages Functions 请求消耗极低

```
├── functions/

├── scripts/
│   ├── sync-icons.mjs         # 本地图标镜像同步脚本（新增物品后运行）

```

## 开拓农村 / 开拓工厂 的数据来源与更新

游戏 `/api/data/defs`（页面主数据源）**不包含**农村与工厂的数值——它们打包在游戏客户端 bundle 里。因此：

- `index.html` 中的 `FARM_FACTORY_DEFS` 数据块由 `scripts/sync-farm-defs.mjs` 从客户端 bundle 提取生成（**不要手改**，只在两个 `==FARM_FACTORY_DEFS_*==` 标记之间自动写入）
- 提取不依赖压缩后的变量名，只用不被改名的对象属性名做锚点（`BASE_OUTPUT` / `processor:!0` / `duration` 等），并在 Node `vm` 里求值后按数据结构认领结果；结构变化会直接报错而不是静默产出错误数据
- **游戏更新数值后**：`node scripts/sync-farm-defs.mjs`（`--check` 只比对不写入，可用于 CI / 部署前检查）
- 修改农村/工厂计算逻辑后，跑自检：`node scripts/test-farm-model.mjs && node scripts/test-farm-ui.mjs`
- 数值口径已与独立反推实现交叉验证：2 万组随机建筑 + 3 千组农村状态**零误差**，18 条配方与阶级推导一致

## 图标链路与故障排查

页面图标加载顺序：`/source/` 边缘代理（缓存 1h）→ 本地 `icons/` 镜像（按文件名匹配）。

若线上出现「新物品贴图空白」，按序检查：

1. **本地镜像是否缺新图标**：`node scripts/sync-icons.mjs --check`，缺则去掉 `--check` 下载
2. **代理回源是否可用**：`curl -I https://<pages域名>/source/items/玄铁锭.png` 看 `x-proxy-cache` 与状态码
3. **lanxi 命名隧道是否健康**：图片源走固定域名 `icons.coldrain.ink`（命名隧道 `mc-icon-proxy`，不会因为重启换域名）。直接测：`curl -I https://icons.coldrain.ink/source/items/玄铁锭.png`；异常时 `ssh lanxi` 后 `docker logs --tail 30 mc-icon-proxy-cloudflared-1` 查看连接状态
4. 注意：上游图片服务器 `203.135.99.28:32001` 对 Cloudflare 边缘 IP 段有 ACL（返回 403/521），从国内家庭宽带直连则正常——这是引入 lanxi 中转的原因

## 本地开发

需要 Node.js。用 Wrangler 起 Pages 本地环境（同时模拟 Functions 代理）：

```bash
npx wrangler pages dev .
```

访问 `http://localhost:8788`。

## 部署

项目即开即用为 Cloudflare Pages 项目：

- **Git 集成**：在 Cloudflare Pages 连接本仓库，构建命令留空、输出目录填 `/` 即可
- **直接部署**：`npx wrangler pages deploy .`
