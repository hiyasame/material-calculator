# 开拓生存 · 材料计算器

一个为《开拓生存》制作的网页工具：**材料合成计算**、**挂机时长估算**、**属性面板计算** 与 **刷怪收益排行**，部署在 Cloudflare Pages 上。

全部游戏数据（物品、配方、怪物掉落、召唤成本、装备词条、Buff 定义）不硬编码，实时来自游戏服务器 `kt.ikui.vip` 的数据接口，经边缘代理缓存加速——游戏更新配方后，页面无需发版即可拿到最新数据。

## 功能

### 📦 材料合成计算

- 同时添加多个合成目标（锻造、NPC 兑换、虚空商队、区域配方统一纳入下拉选择）
- 递归展开合成树，可逐层折叠查看每一级的用量
- 自动汇总到**原子材料**（不可再合成的材料），按数量排序
- 标记每种材料是否**可刷怪获得**，并给出期望掉落最高的怪物
- 装备图标/名称悬浮可查看**属性提示**（品质、槽位、词条、特效）

### ⏳ 挂机时间计算

- 输入目标材料数量，选择刷取怪物，估算需要击杀的次数与**挂机总时长**
- 掉落按**期望值**计算：`掉率 × 掉落数区间均值`，宝袋自动按 loot table 展开
- **击杀耗时估算**：可选择「当前配装」或任意已保存配装，按属性面板的期望伤害 ÷ 怪物平均血量自动估算每只击杀秒数（近战物理伤害按怪物物理抗性折算 `×100/(100+有效抗性×1.5)`，护甲穿透按百分比削减怪物抗性；魔法/真实伤害不受物理抗性影响；怪物每秒回血从 DPS 中扣除，DPS 不足会提示无法击杀；副手弓按固定连射射速计算）；行内「秒/只」可覆盖
- 怪物战斗数值（生命/抗性/回血）口径与游戏 Wiki 一致：品阶基础值 + monsterMod 修正（hpSet/hp/res），Boss（尸王/琉璃王等）用固定血量与回血
- 每只怪物击杀秒数可全局默认、可按行覆盖（召唤 / Boss 自行估计）
- 召唤成本（召唤币、召唤材料）按击杀数换算并汇总
- 支持从合成统计**一键带入**所有可刷材料

### 💰 刷怪收益排行

- **绑定装备预设**：选择「当前配装」或任意已保存配装，按该配装的期望伤害估算每种怪的击杀耗时，计算刷什么最赚钱，列出**时薪 Top 5**
- **收益口径**：`时薪 = (期望掉落折价 − 召唤成本) ÷ 击杀秒数 × 3600`
  - 期望掉落：`期望数量 × 商店出售价`（含神域币，宝袋自动展开），机会成本口径
  - 召唤成本：召唤神域币 + 召唤材料 × 商店出售价
  - 击杀耗时与挂机页同一套公式：物理伤害按怪物抗性折算（护甲穿透削减抗性），魔法/真实伤害不受物理抗性影响，副手弓按固定连射射速，怪物回血从 DPS 扣除；**DPS 打不过回血的怪自动排除**
- **自定义时长**：输入刷怪时长（小时），每张卡片同时显示时薪与该时长的预计总净赚、总击杀数
- **明细透明**：每张卡片分列「期望掉落/只」与「召唤成本/只」逐项金额（`单价×数量=小计`）；无商店卖价的材料不计入金额，单独列入「未估价材料」提示，供自行判断
- 排行概要显示核算范围（可击杀怪数 / 排除数）；抗性开关与挂机页独立，勾选「忽略怪物抗性」可看上限收益

### 👤 属性面板计算

- 按游戏装备栏布局（头盔/胸甲/护腿/靴子/主手 + 护符/项链/戒指/图腾/副手共 10 槽，护符仅 1 个可用槽位）自由搭配装备，实时计算**完整属性面板**
- 计算公式逐条对齐游戏客户端源码的 Calc 系列：`生命 = round((基础20+flat)×(1+pct/100))`、`物伤 = round((基础5~10+装备)×(1+pct/100))`、`攻频 = 1.2×(1+min(攻速,30)/30)+急速×0.35`（实战四舍五入取整）等
- **护符镌刻台**：装备普通/精工/大师护符后按品级选择 1~3 条词条（词条池与数值取自游戏 Wiki：普通 4 条 / 精工 7 条 / 大师 11 条，等概率可重复），支持**太古**开关（数值向上取整 ×1.25，名称加 ★），并按游戏规则预览命名（完美的/有瑕疵的/残余的）
- **收藏室（装备库）**：武器库 / 盔甲库 / 副手库三页签，卡片布局对齐游戏装备库 UI；勾选已入库装备即把收藏属性计入面板（盔甲套装每件一份加成、四件放满额外加一份）
- **收藏数值为游戏真实数据**：内置默认值直接提取自游戏服务器的 `weaponVaultDefs / armorVaultDefs / offhandVaultDefs`（2026-09-07，经登录态 `/api/game/state` 接口获取，非公告转述）；游戏更新后可点「⬇ 从游戏导入」粘贴最新 state JSON 一键刷新（localStorage 持久化，可随时恢复内置值）
- **额外加成**支持手动填入其他来源加成（未收录的收藏室套装等）
- 装备 Buff 自动聚合（套装同名不叠加，取最高等级），并在面板中展示效果说明
- 每项属性附带**贡献明细**（装备 +X ｜ 护符 +Y ｜ 收藏 +Z ｜ 额外 +W），攻速超上限、唯一装备重复佩戴会给出提示
- **输出估算**：近战期望（单次期望 × 实战取整刀数）+ 副手弓（远程伤害 × 连射，固定射速不受攻速影响）+ 合计
- 配装方案可保存/载入（localStorage 持久化），方便横向对比多套搭配

## 技术要点

- **零构建、零依赖前端**：单个 `index.html`，原生 JS + CSS，无框架无打包
- **数据实时化**：页面每次访问经 `/api/data/defs` 拉取上游数据；失败自动回退 `localStorage` 离线缓存；页面驻留时每 30 分钟自动刷新，切回标签页超过 10 分钟也会刷新
- **两个 Cloudflare Pages Functions 边缘代理**：
  - `functions/api/data/defs.js` — 代理游戏数据 API，边缘缓存 5 分钟，上游 5xx/超时自动重试
  - `functions/source/[[path]].js` — 代理上游图片服务器（游戏图标为 HTTP 资源，需转成同源 HTTPS 才能在页面上显示），边缘缓存 1 小时；**多源回退**（lanxi 隧道 → 直连旧 IP），隧道域名失效后可通过 Pages 环境变量 `IMAGE_PROXY_ORIGIN` 免代码更新新地址
- **图标多级回退**：上游代理失败时自动切换到本地 `icons/` 镜像（按文件名匹配）；游戏新增物品后执行 `node scripts/sync-icons.mjs` 一键补齐镜像（`--check` 只报告不下载），避免代理挂掉时新物品贴图空白
- 免费额度友好：数据接口每个边缘节点最多 5 分钟回源一次，图片缓存 1 小时，Pages Functions 请求消耗极低

## 目录结构

```
├── index.html                 # 前端单页应用（全部 UI 与逻辑）
├── functions/
│   ├── api/data/defs.js       # 游戏数据 API 边缘代理（缓存 5 分钟）
│   └── source/[[path]].js     # 图片资源边缘代理（缓存 1 小时，多源回退）
├── scripts/
│   └── sync-icons.mjs         # 本地图标镜像同步脚本（新增物品后运行）
├── icons/                     # 本地图标回退库（200+ 游戏素材）
└── .wrangler/                 # Wrangler 本地缓存（不入库）
```

## 图标链路与故障排查

页面图标加载顺序：`/source/` 边缘代理（缓存 1h）→ 本地 `icons/` 镜像（按文件名匹配）。

若线上出现「新物品贴图空白」，按序检查：

1. **本地镜像是否缺新图标**：`node scripts/sync-icons.mjs --check`，缺则去掉 `--check` 下载
2. **代理回源是否可用**：`curl -I https://<pages域名>/source/items/玄铁锭.png` 看 `x-proxy-cache` 与状态码
3. **lanxi 命名隧道是否健康**：图片源走固定域名 `icons.coldrain.ink`（命名隧道 `mc-icon-proxy`，不会因为重启换域名）。直接测：`curl -I https://icons.coldrain.ink/source/items/玄铁锭.png`；异常时 `ssh lanxi` 后 `docker logs --tail 30 mc-icon-proxy-cloudflared-1` 查看连接状态
4. 注意：上游图片服务器 `203.135.99.28:32001` 对 Cloudflare 边缘 IP 段有 ACL（返回 403/521），从国内家庭宽带直连则正常——这是引入 lanxi 中转的原因

## 本地开发

需要 Node.js。用 Wrangler 起 Pages 本地环境（同时模拟 Functions 代理）：

```bash
npx wrangler pages dev .
```

访问 `http://localhost:8788`。

## 部署

项目即开即用为 Cloudflare Pages 项目：

- **Git 集成**：在 Cloudflare Pages 连接本仓库，构建命令留空、输出目录填 `/` 即可
- **直接部署**：`npx wrangler pages deploy .`

## 数据来源与说明

- 上游数据/图片来自游戏服务器 `kt.ikui.vip`，本项目仅做代理缓存与计算展示，不存储游戏数据
- `icons/` 中的游戏素材版权归游戏方所有
